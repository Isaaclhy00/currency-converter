# Currency Converter

A cross-platform React Native currency converter built with Expo and TypeScript.

## Planned stack

- Expo + Expo Router
- TanStack Query
- Zustand
- AsyncStorage
- Jest and React Native Testing Library
- GitHub Actions

See `PLAN.md` for the implementation roadmap.

## Getting started

Implementation setup is documented in the project plan. The repository is ready for the Expo app to be created in this folder.
